- **OddsPapi Data Formats**: OddsPapi uses generic labels for teams rather than their actual string names. For market outcomes, it returns `1` (Home/Team 1), `2` (Away/Team 2), and `X` (Draw) alongside numerical handicaps like `2 (0:1)`. For market names, it often uses standard placeholders like `Over Under Team 1` instead of embedding the team name (e.g. `Over Under FC Barcelona`). The application logic must perform mappings (e.g. converting `1/X/2` and `Team 1/Team 2` into human-readable team names for the UI, and conversely mapping AI-extracted team names down to generic `1` or `2` for matching) to avoid risky fuzzy string comparisons.
